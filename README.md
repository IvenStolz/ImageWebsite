# Verwendete Packages 
- Lucia: Session Verwaltung
- MongoDB/mongoose: Datenbank für Authentifizierung
- @node-rs/argon2: Passwort hashing
- daisyUI & tailwindCSS: Frontend

Das Projekt wurde wie im Tutorial aus der Vorlesung erstellt und es wurden zusätzlich folgende Befehle verwendet:
- npm i -D daisyui@latest
- npm install -D @tailwindcss/line-clamp
- npm install lucia
- npm install @lucia-auth/adapter-mongodb
- npm install mongoose
- npm install @node-rs/argon2

# MongoDB
- Damit die Database funktioniert muss MongoDB Community Server heruntergeladen werden. [Download](https://www.mongodb.com/try/download/community)
- Beim Download MongoDB Compass mit herunterladen (oder nacher seperat herunterladen).
- Neue Connection erstellen mit URI: mongodb://localhost:27017 für den Standard-Localhost-Port
- Save & Connect
- Svelte Projekt starten
